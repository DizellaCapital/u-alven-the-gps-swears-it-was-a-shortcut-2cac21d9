## The line

> I didn't take the wrong road — my map still lists that cornfield as Route 9, and the lake at the end had a better view than your highway ever did.

146 characters. The GPS talking, smug and defensive, caught red-handed and
blaming the map: the cornfield is still Route 9 on its map, and the lake at
the end had a better view than the highway — a fresh, specific detail
instead of the usual recalculating joke.

## Run it

```sh
python3 main.py  # writes entry.txt to $MAKEFUN_OUTPUT_DIR (fallback /output)
```

`main.py` (stdlib only) validates the line is 1–200 characters and a single
line, writes it to `$MAKEFUN_OUTPUT_DIR/entry.txt` (fallback `/output`),
then reads it back to verify the written bytes match.
